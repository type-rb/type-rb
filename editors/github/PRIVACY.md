# Privacy policy for TypeRB Syntax Highlighting for GitHub

Last updated: August 22, 2026

TypeRB Syntax Highlighting for GitHub highlights TypeRB source code on
`github.com` in the user's browser.

The extension does not collect analytics, identifiers, browsing history, or
repository contents. It does not send page or source data to TypeRB or to any
service outside `github.com`.

To preserve multiline syntax state in pull request diffs, the extension may
request the exact `.trb` file revisions referenced by the GitHub page currently
being viewed. These same-origin requests are sent only to `github.com`, use the
user's existing GitHub session, and access only files that GitHub has already
authorized the user to view. Retrieved source is cached only in memory for the
current page session and is discarded when the page is closed.

Questions or privacy concerns can be reported through the
[TypeRB issue tracker](https://github.com/type-rb/type-rb/issues).
