Browser tools are temporarily paused

The hosted playground and interactive tour, including Run, Transpile and Format, are paused during the v0.5 Native transition. Documentation continues to be updated.

Use the Native command-line REPL for interactive evaluation. Local trb play and trb tour remain available in the separately installed Go implementation; the Native commands do not invoke it automatically.

See the implementation transition for scope and implementation identity. Use the Go implementation's installation instructions and avoid replacing your Native executable unintentionally.
